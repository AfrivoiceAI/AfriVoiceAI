# MVP boundaries
Included: auth, free usage counter, MongoDB history, feedback, consent preference fields, Ollama text adapter, optional Kokoro TTS, Whisper ASR and FLUX image adapter.
Not included: video, billing, moderation console, email verification, account deletion, production media storage, async job queue, consent withdrawal workflow or model fine-tuning.
Next: validate API and UI; test local models; build a native-speaker-reviewed Nigerian speech benchmark; implement privacy/deletion/withdrawal and secure storage before accepting voice contributions.
